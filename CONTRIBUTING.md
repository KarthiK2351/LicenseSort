# Contributing to OSS License Sorter

Thanks for your interest in improving **OSS License Sorter**! This project is licensed under the **Apache License 2.0**, and contributions are very welcome.

## Ways to contribute
- 🐞 Report bugs (repro steps, browser/OS, screenshots if possible)
- 💡 Suggest features or UX polish
- 🧪 Write tests or add accessibility improvements
- 🧹 Refactor code or improve comments/docs

## Getting started (local)
1. Clone or download the repo
2. Open `index.html` in your browser (no build needed)
3. Make changes in `app.js` and/or `styles.css`

## Coding guidelines
- Keep the game **framework‑free** and lightweight (plain JS/CSS/HTML)
- Prefer **SPDX headers** (`Apache-2.0`) in new files
- Keep the license pool and categories in `ALL_LICENSES` coherent
- Don’t introduce libraries unless there’s a strong reason

## Commit messages
- Use concise, imperative style: `Add tooltip for MPL-2.0`, `Fix deck repeat logic`

## Pull requests
1. Fork the repository & create a feature branch
2. Ensure the page loads cleanly in latest Chrome/Firefox/Edge
3. Fill the PR template (what/why, screenshots/gifs)

## Issue template (suggested)
**Summary**: …  
**Steps to reproduce** (if bug): …  
**Expected / Actual**: …
